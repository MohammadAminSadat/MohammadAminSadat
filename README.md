## About

🟢 **Open to new opportunities** — actively looking for full-time roles in ADAS, embedded software, or autonomous systems engineering.

I'm an ADAS and Embedded Software Engineer with hands-on ownership of an Autonomous Emergency Braking (AEB) module end-to-end — requirements through MiL/SiL/HiL regression testing — on a safety-critical production codebase maintained to **ISO 26262 ASIL-B**.

Background is Mechatronics (MSc) and Mechanical Engineering (BSc). Over time that's narrowed to one thing I care about: writing embedded software — increasingly with ML in the loop — that a car's safety systems can actually depend on.

- 🛡️ **Functional safety** — ISO 26262 ASIL-B, MiL/SiL/HiL regression pipelines

- 🤖 **Applied ML** — perception/classification models for automotive use cases
